# Источник данных CSV

Класс: `Sholokhov\Exchange\Source\Csv`

## Введение

Источник данных предназначен для последовательного чтения CSV-файлов без загрузки всего файла в память.  
Позволяет работать с большими файлами, экономя ресурсы сервера.

Чтение производится построчно, строки конвертируются в массивы и сразу передаются в обмен.  
Кодировка данных может быть автоматически определена и преобразована в нужную.

> ⚠️ Внимание
>
> Для работы необходимо, чтобы Reader возвращал поток с CSV данными.

## Конструктор и Reader

При инициализации объекта в конструктор необходимо передать **Reader**, реализующий интерфейс [DataReaderInterface](/2.3.x/reader/).  
Reader может быть любым: `LocalFileReader`, `HttpReader`, `MemoryReader` и др.

Вторым параметром указывается кодировка CSV-файла. Если параметр не указан, используется `SITE_CHARSET`.

**Пример создания источника CSV**
```php
use Sholokhov\Exchange\Source\Csv;
use Sholokhov\Exchange\Reader\LocalFileReader;

// Создаём Reader
$reader = new LocalFileReader('/path/to/file.csv');

// Передаем Reader в конструктор Csv источника
$source = new Csv($reader, 'UTF-8');

// Пропускаем заголовок
$source->setSkipHeader(true);

// Настройка разделителя и ограничителя
$source->setSeparator(';')
       ->setEnclosure('"')
       ->setEscape('\\');

foreach($source as $row) {
    var_dump($row);
}
```

## Настройки CSV источника

| Название   | 	Тип данных | 	Значение по умолчанию | 	Описание                                                 |
|------------|-------------|------------------------|-----------------------------------------------------------|
| skipHeader | 	bool       | 	true                  | 	Пропускать первую строку (заголовок)                     |
| separator  | 	string     | 	`,`	                  | Символ-разделитель полей                                  |
| enclosure  | 	string	    | `"`	                   | Символ-ограничитель поля                                  |
| escape	    | string	     | `\`                    | 	Символ экранирования                                     |
| length     | 	int        | 	0                     | 	Максимальная длина читаемой строки                       |
| encoding   | 	string     | 	SITE_CHARSET          | 	Кодировка файла, в которую будут конвертироваться данные |


## Формат CSV
Пример CSV-файла:

```
id;name;color_id;color
15;Тут название;33;Черный
16;Тут название2;12;Белый
```

## Результат чтения
```php
array(4) {
  ["id"]=> 
  string(2) "15"
  ["name"]=> 
  string(23) "Тут название"
  ["color_id"]=> 
  string(2) "33"
  ["color"]=> 
  string(12) "Черный"
}

array(4) {
  ["id"]=> 
  string(2) "16"
  ["name"]=> 
  string(24) "Тут название2"
  ["color_id"]=> 
  string(2) "12"
  ["color"]=> 
  string(10) "Белый"
}
```

## Особенности

- Каждая строка CSV читается последовательно, что позволяет работать с большими файлами.
- Кодировка автоматически определяется с помощью `mb_detect_encoding` и конвертируется через `Bitrix\Main\Text\Encoding`.
- Заголовок можно пропускать с помощью метода `setSkipHeader()`.
- Разделитель, ограничитель и символ экранирования настраиваются через `setSeparator()`, `setEnclosure()` и `setEscape()`.
