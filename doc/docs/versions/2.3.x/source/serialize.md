# Источник данных SerializeItem

Класс: `Sholokhov\Exchange\Source\SerializeItem`

## Введение

Источник данных предназначен для работы с сериализованными строками PHP (`serialize`).  
Позволяет преобразовать сериализованные данные в массивы и передавать их в механизм обмена.  
Источник поддерживает как одиночные значения, так и множественные данные.

> ⚠️ Внимание
>
> Для работы необходимо, чтобы Reader возвращал поток с сериализованной строкой.

## Конструктор и Reader

При инициализации объекта в конструктор необходимо передать **Reader**, реализующий
интерфейс [DataReaderInterface](/2.3.x/reader/).  
Reader может быть любым: `LocalFileReader`, `MemoryReader`, `HttpReader` и др.

Вторым параметром указывается, являются ли данные множественными (`true`) или одиночными (`false`). По умолчанию данные
множественные.

**Пример создания источника SerializeItem**

```php
use Sholokhov\Exchange\Source\SerializeItem;
use Sholokhov\Exchange\Reader\LocalFileReader;

// Создаём Reader
$reader = new LocalFileReader('/path/to/data.txt');

// Передаем Reader в конструктор SerializeItem
$source = new SerializeItem($reader, true);

foreach($source as $row) {
    var_dump($row);
}
```

## Настройки SerializeItem

| Название | 	Тип данных          | 	Значение по умолчанию | 	Описание                                      |
|----------|----------------------|------------------------|------------------------------------------------|
| reader   | 	DataReaderInterface | 	—	                    | Источник потока с сериализованными данными     |
| multiple | 	bool                | 	true                  | 	Данные являются множественными или одиночными |

## Формат данных

Сериализованная строка PHP:

```php
// Один объект
$a = serialize(['id'=>15,'name'=>'Тут название']);

// Множественные объекты
$b = serialize([
    ['id'=>15,'name'=>'Тут название'],
    ['id'=>16,'name'=>'Тут название2'],
]);
```

## Результат чтения

```php
array(2) {
  ["id"]=> 
  int(15)
  ["name"]=> 
  string(23) "Тут название"
}

array(2) {
  ["id"]=> 
  int(16)
  ["name"]=> 
  string(24) "Тут название2"
}
```

## Особенности

- Данные десериализуются через стандартную функцию PHP `unserialize`.
- Если `multiple = true`, данные всегда возвращаются как массив объектов.
- Если `multiple = false`, даже одиночное значение оборачивается в массив для совместимости с итератором.
- Каждое чтение источника использует отдельный поток, что позволяет безопасно работать с памятью.
