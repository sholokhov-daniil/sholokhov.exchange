# Источник данных EntitySource

Класс: **Sholokhov\Exchange\Source\Entities\EntitySource**

## Введение

Источник данных предназначен для работы с сущностями через провайдер (`EntityProviderInterface`).  
Позволяет загружать элементы батчами, что экономит память при обработке больших объемов данных.  
Итерация по данным происходит постепенно, с подгрузкой следующего батча по мере необходимости.

> ⚠️ Внимание
>
> Для работы требуется провайдер сущности, реализующий интерфейс [EntityProviderInterface](/2.3.x/provider/entity/).

## Конструктор и провайдер

При инициализации объекта в конструктор необходимо передать **EntityProvider**, который умеет выполнять запросы и
фильтровать данные.

**Пример создания источника**

```php
use Sholokhov\Exchange\Source\Entities\EntitySource;
use Sholokhov\Exchange\Provider\Entity\MyEntityProvider;

$provider = new MyEntityProvider();
$source = new EntitySource($provider);

foreach($source as $entity) {
    var_dump($entity);
}
```

## Особенности EntitySource

- Данные подгружаются батчами (`BatchIteratorTrait`).
- Итерация безопасна при больших объемах данных — не требуется держать весь результат в памяти.
- Каждый элемент должен иметь уникальный ID (`ID`), используемый для курсорной пагинации.
- Источник автоматически отслеживает последний обработанный ID и подгружает следующие записи.

## Настройки и методы

| Название | 	Тип данных              | 	Описание                                 |
|----------|--------------------------|-------------------------------------------|
| provider | 	EntityProviderInterface | 	Провайдер данных для получения элементов |

## Пример использования с фильтром

```php
$provider = (new MyEntityProvider())
    ->setFilter(['ACTIVE' => 'Y'])
    ->setOrder(['ID' => 'ASC']);

$source = new EntitySource($provider);

foreach($source as $entity) {
    echo "ID: " . $entity['ID'] . "\n";
    echo "Название: " . $entity['NAME'] . "\n";
}
```

## Характеристики работы
- Батчи подгружаются по мере итерации.
- Если батч пустой, итерация завершена.
- Поддерживается сброс итератора и повторная итерация через `rewind()`.
