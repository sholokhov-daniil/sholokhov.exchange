# MemoryReader

`MemoryReader` — Reader для работы с данными, хранящимися в памяти.  
Позволяет использовать массивы, строки или скалярные значения в качестве источника данных.  
Возвращает поток (`resource`) при каждом вызове `read()`.

---

## Назначение

- Использовать **данные прямо из памяти** (массивы, строки, числа, float)
- Преобразовывать их в поток `resource` для совместимости с Source классами
- Поддержка независимых потоков: изменения потока вне Reader **не влияют** на внутреннее состояние

---

## Рекомендации
- Использовать `MemoryReader` для тестов или когда данные уже находятся в памяти
- Для больших данных лучше использовать `LocalFileReader` или `HttpReader`, чтобы не держать всё в памяти одновременно
- Поток всегда нужно закрывать через `fclose()` после использования

---

## Пример использования

```php
use Sholokhov\Exchange\Reader\MemoryReader;

// Массив данных
$data = ['one', 'two', 'three'];

// Создание Reader
$reader = new MemoryReader($data);

// Получение потока
$stream = $reader->read();

// Чтение содержимого
$content = stream_get_contents($stream);
fclose($stream);

// $content = "one\ntwo\nthree"
```

## Основной метод

`read()`  
Создаёт новый поток с текущим содержимым данных.

**Возвращает:**  
`resource` — поток для чтения данных

**Исключения:**  

| Исключение       | Причина                    |
|------------------|----------------------------|
| ReaderException	 | Ошибка при создании потока |

## Принципы работы

1. Входные данные нормализуются в строку:
    - Массив → строки, разделённые \n
    - Скалярные значения → строка
2. Создаётся новый поток php://temp
3. В поток записывается нормализованное содержимое
4. Поток возвращается для чтения

> Важно: каждый вызов `read()` создаёт **новый независимый поток**, 
> поэтому изменение потока вне класса **не влияет** на внутренние данные.

## Нормализация данных

- **Массив**: каждый элемент преобразуется в строку и объединяется через перенос строки
- **Скалярные значения** (`string`, `int`, `float`) приводятся к строке

```php
$data = ['one', 2, 3.5];
$reader = new MemoryReader($data);
$stream = $reader->read();
$content = stream_get_contents($stream);
// $content = "one\n2\n3.5"
```

## Пример с Source

```php
use Sholokhov\Exchange\Reader\MemoryReader;
use Sholokhov\Exchange\Source\Json;

$data = [
    ['id' => 1, 'name' => 'Alice'],
    ['id' => 2, 'name' => 'Bob']
];

$reader = new MemoryReader(json_encode($data));

$source = new Json($reader, [
    'multiple' => true
]);

foreach ($source as $item) {
    // $item = ['id' => 1, 'name' => 'Alice'], потом ['id' => 2, 'name' => 'Bob']
}
```
