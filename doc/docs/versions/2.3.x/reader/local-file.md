# LocalFileReader

`LocalFileReader` — класс для чтения данных из локальных файлов в виде потокового ресурса (resource).  
Используется как низкоуровневый источник данных для различных источников (Json, CSV, XML и др.).

---

## Назначение
- Чтение локальных файлов
- Работа с большими файлами
- Потоковое чтение
- Возврат ресурса для дальнейшего чтения

## Важные замечания
- Ресурс **нужно закрывать** с помощью `fclose($resource)`
- Reader не **валидирует содержимое файла** — это задача Source

## Ограничения
- Работает только с локальной файловой системой
- Не поддерживает HTTP, FTP, S3 и другие удалённые источники

---

## Архитектура

- Реализует интерфейс `DataReaderInterface`
- Используется в источниках данных:
    - Json
    - CSV
    - XML

---

## Поток работы

1. Создание объекта:

```php
$reader = new LocalFileReader('/path/to/file.json');
```

2. Чтение файла:

```php
$resource = $reader->read();
```

3. Использование ресурса:

```php
$content = stream_get_contents($resource);
fclose($resource);
```

> Важно закрывать ресурс после использования, чтобы избежать утечек памяти и блокировки файлов.

## Особенности

- Потоковое чтение (stream) — подходит для больших файлов
- Безопасный режим открытия: fopen($path, 'rb')
- Разделение ответственности: Reader открывает файл, Source парсит данные, Mapper преобразует

## Пример использования с источником

```php
use Sholokhov\Exchange\Source\Json;
use Sholokhov\Exchange\Reader\LocalFileReader;

$reader = new LocalFileReader('/data.json');

$source = new Json($reader);

foreach ($source as $item) {
    // обработка данных
}
```
